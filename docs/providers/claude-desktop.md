# Claude 桌面登录与 CLI 备用（macOS，v1.9.2）

优先跟随 Claude 桌面端当前账号。桌面凭据过期或被官方拒绝时，先核对 CLI 凭据的官方账号与组织，完全匹配才作备用。没有桌面登录的机器保留原 CLI 查询方式；已经跟随桌面账号后，不能因账号消失悄悄切到另一个 CLI 账号。

## 读取与查询

- 读取 `~/Library/Application Support/Claude/config.json` 的当前账号和 `oauth:tokenCacheV2`；只选当前账号、当前组织及具有 `user:profile` 权限的有效凭据，优先权限最少的凭据。
- 使用指定钥匙串服务 `Claude Safe Storage` / `Claude Key` 解密 Electron v10/v11 数据。解密密钥只在当前进程内缓存，主动授权操作会重新读取；不改写桌面缓存或 CLI 登录，不自行刷新官方令牌。
- 当前组织优先以桌面 `lastActiveOrg` 记录为准；仅在没有活动组织记录且缓存只有一个组织时推断。多组织或活动组织没有对应登录时，停止查询并提示在桌面端确认。
- 只向 `https://api.anthropic.com/api/oauth/profile` 和 `/api/oauth/usage` 发送对应凭据，不读取浏览器登录，不发送模型请求。身份核对按凭据摘要缓存，凭据轮换后重新核对。
- 两种来源共用两分钟轮询和限流等待，429 不触发轮换。等待期间只核对本机账号/组织选择，不新增网络或钥匙串请求。
- 账号或组织改变时清除旧额度；请求途中发生切换，拒绝旧响应。详情显示当前登录来源，便于区分桌面和备用登录。

## 验证范围

本机 Claude Desktop 4.4212.0 的桌面 OAuth 身份与额度接口已真实返回 200；桌面网页登录会话路径返回 403，因此没有接入该网页路径。模拟加密数据验证了账号/组织隔离、过期与不同权限记录；模拟 HTTP 验证桌面优先、CLI 身份匹配和共享限流。本功能从 macOS v1.9.2 起提供，Windows 未接入桌面凭据。
