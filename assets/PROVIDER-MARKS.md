# Provider marks

The small, monochrome menu-bar marks identify connected services; they are not the QuotaNest application logo.

- Codex: OpenAI blossom outline from the SVG served by https://openai.com/favicon.svg (retrieved 2026-10-12).
- Claude Code: pixel adaptation of the mascot displayed by the official Claude Code terminal client: https://github.com/anthropics/claude-code.
- Antigravity: official silhouette from https://www.agy.dev/favicon.svg (retrieved 2026-10-12), with background and color effects removed for menu-bar legibility.

Names and brand marks belong to their respective owners and are not licensed under this project's MIT license. QuotaNest is an independent community project, with no endorsement or affiliation.

## Bundled official PNG marks

The following original images are displayed at menu-bar size without redrawing the logo. Retrieved or checked on 2026-10-12. The original three vector marks above remain unchanged.

- `provider-marks/zcode.png`: official Zcode desktop source, `public/logo/icons/128x128.png`: https://github.com/zai-org/ZCode/blob/aac4755666d09fdcd70272fcf063c077a639015f/public/logo/icons/128x128.png .
- `provider-marks/deepseek.svg`: official DeepSeek API documentation favicon, linked by https://api-docs.deepseek.com/api/get-user-balance/ : https://api-docs.deepseek.com/img/favicon.svg (retrieved 2026-10-23). Displayed without redrawing the logo for the DeepSeek wallet.

Build packaging copies `assets/provider-marks/` to the application bundle's `Contents/Resources/provider-marks/`. No image is fetched at runtime. These marks identify the corresponding service and do not imply endorsement.
